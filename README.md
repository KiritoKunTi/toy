# uzatu-invite

Premium cinematic wedding invitation for Думан & Ақсауле.

## Develop

```bash
yarn install
yarn dev
```

## Build / deploy

```bash
yarn build
firebase deploy --only hosting:toy
```

Build output goes to `build/` for Firebase Hosting.

## Content

Edit wedding copy, photos, timeline, and RSVP labels in `src/data/invitation.ts`.
